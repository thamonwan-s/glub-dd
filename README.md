# Glub DD

A multimodal late-night transit planner that compares routes by cost, travel time, and transportation options.

## About

glub-dd is a personal project created to solve a practical problem: finding affordable and efficient ways to travel after midnight when most public transportation services are limited.

The project aims to explore routes that combine different modes of transportation, such as:

- 🚌 Bus
- 🚆 Train
- 🚇 MRT / BTS
- 🏍️ Motorcycle taxi
- 🚕 Taxi
- 🚶 Walking

Rather than focusing on a single "best" route, the system will compare different options based on:

- Cost
- Travel time
- Transportation modes
- Number of transfers
- Willingness to take a small detour

## Project Goals

- Display transportation locations and routes on an interactive map.
- Store transportation data such as locations, fares, and operating hours.
- Find and compare multiple possible routes.
- Identify the cheapest and fastest routes.
- Support multimodal routes that combine public transportation with taxis or motorcycle taxis.
- Provide practical route alternatives for late-night travel.

## Project Motivation

This project started from a personal need to find the most affordable way to travel after midnight by combining whatever transportation options are still available.

The goal is to turn that real-world problem into a practical software project while learning web development, data processing, mapping, and route optimization.
